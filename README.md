# Website Build Idea Finder

A step-by-step guide to **find, validate and build a website idea** using free tools
(Reddit, Quora, Ahrefs, Instant Domain Search) and AI.

> Goal: don't build a website nobody wants. Find a real problem, verify demand, study
> rivals, find "golden" low-competition keywords, pick a `.com` domain, then build with AI.

## Quick overview

**Part 1 — Research & Validation**

1. **Find the Problem** — your own problems + Reddit/Quora + make it micro.
2. **Is it Worth it?** — verify idea with Ahrefs free keyword generator (volume ~100–1000).
3. **Competitor Analysis** — study rivals, find weaknesses & bugs.
4. **Traffic Checker** — find golden low-competition keywords.

**Part 2 — Domain**

5. **Find & Choose Domain** — main keyword in a `.com` (buy last).

**Part 3 — Build**

6. **Build with AI** — AI writes the code; site must work before buying the domain.

**The stack:** [Claude Code](https://claude.com/product/claude-code) /
[OpenCode](https://opencode.ai/) · [Astro](https://astro.build/) ·
[Cloudflare](https://www.cloudflare.com/) ($0 for static sites)
